# Logo With Bezier Curves

Projekt, v katerem je logotip narisan z **Bézierjevimi krivuljami**.

Bézierjeva krivulja je določena z začetno točko, končno točko in kontrolnimi točkami, ki določajo njeno ukrivljenost. Z več povezanimi krivuljami se da narisati gladke oblike, kot so logotipi in črke.

- **Kvadratna** krivulja: 1 kontrolna točka
- **Kubična** krivulja: 2 kontrolni točki
